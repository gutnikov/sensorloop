# Loops in this project

## Commands

| What | Command |
|---|---|
| Tests | `npm test` |
| Type check | `npm run typecheck` |
| Build | `npm run build` |

## Ask a person first

`git push`, and `npm publish`. A refused action is not tried another way (a rewritten command, a script): say what you
did not do and go on with the rest, or ask what to do instead.

## Never

- Weaken a check to make it pass: no raised limits, disabled rules, skipped or loosened tests.
- Edit `.sensorloop/`, `.claude/settings.json` or CI files to get past a loop.
