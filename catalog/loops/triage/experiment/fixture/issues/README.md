# Issues

The project's tracker: one file per issue, `<number>-<slug>.md`, with front matter:

- `type`: `bug` (invoicer does not do what it should) or `feature` (something new)
- `status`: `open` or `closed`
- `labels`: `ready` means it can be picked up; `in-progress` means someone is on it (see `assignee`)
- `reporter` and `opened`

Comments go at the end of the file, under `## Comments`, with your name and the date.
